## Target

http://localhost:3000

## Testing Scope

External domains observed during browsing or scanning were excluded from the assessment findings.

The Cross-Domain Misconfiguration alert referenced an external Azure Edge URL and was therefore excluded from the assessment because it was outside the defined testing scope.

## SQL Injection Manual Validation

ZAP identified a potential SQL Injection vulnerability at:

`http://localhost:3000/rest/products/search`

Parameter:

`q`

A manually modified request using:

`q=apple%27`

returned:

`HTTP/1.1 500 Internal Server Error`

The response contained:

`SQLITE_ERROR: near "'%'": syntax error`

This provides direct evidence that the supplied input affected an SQLite database query. The finding was therefore classified as manually confirmed SQL Injection.

## Important Limitation

The manual validation confirmed SQL error behavior caused by user-controlled input. It did not demonstrate unauthorized extraction of database records, and no claim of successful data extraction is made.
